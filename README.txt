FISCHER - CONTROLE DE TEMPO DE MÁQUINAS

ARQUIVO PRINCIPAL
- index.html

COMO ABRIR
1. Extraia o arquivo ZIP.
2. Abra o index.html no Google Chrome ou Microsoft Edge.

RECURSOS INCLUÍDOS
- Cronômetro independente para cada máquina.
- Ações: Operação, Uso, Pausa e Manutenção.
- Processo/atividade, operador, turno e observações.
- Encerramento automático do período anterior ao trocar de ação.
- Registro manual e edição de registros.
- Dashboard por dia, mês ou período personalizado.
- Acumulados por ação, máquina e processo.
- Histórico, filtros e exportação CSV.
- Cadastro e desativação de máquinas.
- Logo Fischer incorporada no próprio HTML.
- Layout responsivo para computador, tablet e celular.

ARMAZENAMENTO
Esta primeira versão armazena os dados no localStorage do navegador. Os registros
ficam somente no dispositivo e perfil de navegador onde foram criados.

PARA USO CORPORATIVO MULTIUSUÁRIO
Será necessário conectar o frontend a uma API e banco de dados central, com login,
permissões, backup e auditoria. A interface já pode ser aproveitada como base.
